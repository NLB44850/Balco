# Plantes frileuses face au froid : ce que disent les sources (15/10)

Question (chantier « Plante hors saison », étape 1) : pour chaque plante, est-elle rustique ou frileuse ; pour une
frileuse, sous quelle température de nuit souffre-t-elle ; la rentrer à l’intérieur vaut-elle la peine ?
Règle du projet : une valeur n’est gardée que si 2 sources la confirment, sinon elle est affichée comme estimation.

Méthode : recherche web du 15/10 (extraits des résultats : la session ne peut pas ouvrir les pages). Point de départ :
la liste des alertes gel (`care.frostSensitive` du catalogue). Données dans `lib/plants/cold-hardiness.ts`.

Ce que les sources donnent rarement : une température de nuit précise. Elles disent plus souvent « craint le gel »,
« disparaît aux premières gelées ». Dans ce cas, le seuil est repris du catalogue (seuil des alertes gel) et marqué
« estimation ». Aucune fréquence d’arrosage d’hiver n’est chiffrée, sauf pour le citronnier (étape 4).

## Rustiques (65 plantes)

Elles passent l’hiver dehors, au repos : Menthe, Persil, Ciboulette, Thym, Romarin, Coriandre, Sauge officinale, Origan, Mélisse, Estragon, Cerfeuil, Sarriette, Hysope, Ail des ours, Agastache, Livèche, Plante huître, Fraisier, Petits pois, Salade à couper, Laitue pommée, Roquette, Épinards, Blettes, Mâche, Chou kale, Cresson alénois, Oseille, Pak choï, Mizuna, Micro-pousses, Épinard-fraise, Arroche, Claytone de Cuba, Moutarde de Chine, Chou-rave, Poireau perpétuel, Radis, Carottes rondes, Oignons botte, Betterave, Navets, Ail, Crosnes du Japon, Soucis, Lavande, Bourrache, Violas et pensées, Phacélie, Bleuets, Alysse odorante, Pois de senteur, Géranium vivace, Verveine de Buenos Aires, Œillet mignardise, Mufliers, Fuchsia rustique, Framboisier nain, Myrtillier, Groseillier, Figuier nain, Fraisier des bois, Kiwaï, Cassissier, Mûres sans épines.

Exceptions : protégées par les alertes gel mais pas frileuses ici :
- rosemary : Rustique en pot jusque vers -10 °C, pot protégé (voile, pied paillé) : il reste dehors.
- microgreens : Semées toute l'année, à l'intérieur l'hiver : pas de fin de saison.
