# Captures de Balco (14 octobre 2026)

Prises dans l'app web (même code que l'app Android), sur un téléphone simulé (Pixel 7), avec une météo simulée à Lyon,
mi-octobre (sauf mention). À joindre au récap `docs/recap-pour-claude.md` dans une conversation sur claude.ai. Pour les
refaire : `bash scripts/captures.sh` (dans la session Claude Code).
